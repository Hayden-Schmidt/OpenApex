# Rider mesh screens

Terminal designs for blueprint 04 (rider mesh). Add one file or subfolder per U-number (U1-U12),
matching the U-table in `docs/blueprints/04_rider_mesh.md`, then link it in that table's
"Design link" column. Today's friend prompt, which the U1-U4 flows replace, is in
`../06-add-friend/`.

First build (2026-10-01): `sim_states_240.png` is the simulator render of U1-U5 at 240 px
(`firmware/sim_lvgl --pair <scenario>`). Redesign freely; the firmware hooks stay the same.
